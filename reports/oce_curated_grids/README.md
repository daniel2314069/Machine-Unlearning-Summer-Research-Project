# Curated OCE visual evidence

These four grids preserve representative qualitative evidence while the raw
generated images and reproducible model weights remain outside Git.

- `correspondence_joint_n2_cat_to_dog.png`: the official joint-N2
  correspondence result for cat-to-dog.
- `correspondence_reciprocal_cat_to_dog.png`: the reciprocal cat/dog overlap
  probe.
- `mixed_joint_cat.png`: the mixed joint-versus-single comparison for the cat
  prompt.
- `overlap_cycle3_wolf.png`: the three-concept overlap-cycle result for the
  wolf prompt.

The complete numerical evidence, resolved settings, and run state remain in
the corresponding experiment directories. Full raw images and checkpoints are
kept locally or regenerated on the compute server.
